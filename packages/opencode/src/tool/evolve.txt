Query self-evolution state: friction metrics, dashboard, snapshots, rollback, scenario fixtures, and evaluation gates.

Operations:
- metrics: quantify tool churn / re-reads / corrections / Human Attention Cost
- dashboard: summarize .oimo/evolve INDEX, backlog, briefs, friction, history
- snapshot / list_snapshots / rollback: .oimo asset checkpoints
- scenarios: list built-in + project fixtures under .oimo/evolve/scenarios/*.json
- scenario_prompt: return the runnable prompt for scenario_id
- scenario_score: score an observation JSON against scenario budgets
- evaluate: coarse friction window compare
- gate: combine friction compare + optional scenario_score into one adopt/reject signal

Prefer this tool over ad-hoc SQLite when running /evolve or /self-improve.
After writing a product brief:
1. workflow evolve-review with args.brief
2. If approved by the user, workflow evolve-apply with args.brief and args.approved=true
